# ViewHelper metadata

`viewhelpers.json` is generated from the [TYPO3 14.3 ViewHelper reference](https://docs.typo3.org/other/typo3/view-helper-reference/14.3/en-us/Index.html).
Documentation text is by the TYPO3 contributors, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Descriptions are shortened; selected argument value lists are added by this project.
The source URL is retained for every ViewHelper. This data license is separate from the extension's MIT license.

Regenerate with `npm run update:viewhelpers`, then review the diff and run `npm test`.
Generation requires internet access; normal completion and hover work offline.
